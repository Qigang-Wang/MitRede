# 所内互动演示平台

本目录记录“基于 PDF 的网页互动演示平台”的需求与技术方案。

平台定位：面向所内会议、汇报、培训、研讨和课堂场景，将已有 PowerPoint 转换为 PDF 后上传，在 PDF 页面之间插入投票、评分、词云、开放问答及 AI 总结页面。主持人通过网页播放，参与者通过二维码或房间码在手机上匿名参与，结果实时显示。

当前阶段不考虑商业化、计费、多租户销售和公开互联网运营，优先考虑：

1. 所内部署和数据可控。
2. 演示现场稳定。
3. 用户无需重新制作已有 PPT。
4. 参与者无需安装 App 或注册账号。
5. 系统容易运维和继续开发。

## 当前建议

第一阶段先做一个可在所内网络部署的 MVP，支持 PDF 演示、选择题、开放问答、匿名加入、实时同步和结果导出。评分、词云和 AI 总结在核心播放链路稳定后加入。

建议采用 TypeScript 单语言的模块化单体架构：React + Vite 前端、NestJS 后端、Socket.IO 实时通信、PostgreSQL + Prisma、Redis + BullMQ、MinIO 和独立 Worker，以 Docker Compose 部署。PDF 由受限 Worker 调用 MuPDF 或 Poppler 处理。首版不引入 Kubernetes 或微服务。
